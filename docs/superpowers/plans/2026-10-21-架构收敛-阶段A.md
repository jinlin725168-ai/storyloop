`load_declaration` 校验并在不合法时抛 `ValueError`（信息里带出错的键）：`version == 1`；每个条目的 `module` 是已声明的架构模块；`zone` 在 `ZONES`；`split` 缺省或在 `SPLIT_STAGES`；豁免的 `until` 在 `EXEMPTION_STAGES` 且 `reason` 非空。缺省的 `exemptions`、`cycles`、`invariants` 视为空。

`code_modules`：遍历 `package` 下全部 `.py`，模块名由相对路径的 `parts` 用 `.` 连接；`pkg/__init__.py` 记为 `pkg`；根目录的 `__init__.py` 不计；`__main__.py` 记为 `__main__`。

`classify`：先查精确名；没有就在以 `.*` 结尾的通配里找前缀匹配（`testing.smoke_harness.*` 匹配 `testing.smoke_harness` 本身和其下所有模块），取最长前缀；都没有就抛 `KeyError(name)`。

`undeclared` 返回 `classify` 抛 `KeyError` 的模块名，排好序。`stale_entries` 返回不存在的精确条目，以及一个模块都匹配不到的通配条目。

```python
@dataclass(frozen=True)
class Violation:
    source: str; target: str; rules: tuple[str, ...]   # 取值 "upward"、"base_imports_mutable"

def import_graph(package: Path) -> dict[str, set[str]]
def violations(declaration: Declaration, graph: dict[str, set[str]]) -> list[Violation]
def unexempted(declaration: Declaration, found: list[Violation]) -> list[Violation]
def stale_exemptions(declaration: Declaration, found: list[Violation]) -> list[Exemption]
def cycle_members(graph: dict[str, set[str]]) -> set[str]
```

`import_graph`：对每个模块用 `ast.walk` 遍历整棵树（因此包括函数体和 `if TYPE_CHECKING:` 块）。`ImportFrom` 的相对导入按模块所在包和 `level` 解析；`from <pkg> import x` 中 `x` 是已知子模块时，边指向子模块，否则指向 `<pkg>`；绝对导入只看 `storyloop.` 开头的。只保留指向已知模块、且不是自身的边。

`violations`：对每条边 `a → b`，若 `rank(a) < rank(b)` 记 `"upward"`；若 `a` 的 zone 是 `base`、`b` 的是 `mutable` 记 `"base_imports_mutable"`；至少有一条规则才产生 `Violation`。结果按 `(source, target)` 排序。

`unexempted` 返回不在豁免里的违规（按 `(source, target)` 匹配）；`stale_exemptions` 返回不再出现的豁免。`cycle_members` 返回所有规模大于 1 的强连通分量的成员（Tarjan 算法，递归深度设到 10000）。
