## Global Constraints

- 八文档名、响应 schema、CLI、底座边界和错误码不变；不新增第九份必需文件。
- 不改引擎源码、配置、依赖或审批判定。不得读取真实凭证/环境文件/私密缓存/生产数据。
- 事实局部 ID、三种来源状态与独立核验结果、观测完整 SHA；保留冲突、待确认和有证据的不适用。
- 候选包括七正文和附加知识正文，排除 README 汇总及 errata。先每正文抽 hash 首条，再全局补足 min(N,max(7,D,ceil(10%N)))；固定 16 随机字节种子，完整清单 UTF-8 排序/摘要可重放。
- 每 survey 自检；10 个变更/30 天维护者发起复核，无自动调度或额外模型调用。
- 未覆盖概念需同时人工补 body 与 append，未完成不签收；批准提交与 BASE 成功分别记录。
- Q6 依赖采用实际 PR17 已合入的限定验收，本次用户明确授权启动；不得追认原 Q10 全通过。
- Q7 最多 Codex、Claude 各一次公开小仓库真实 survey；每次都记录，不重试凑合规。其他验证离线完成。
