# 子项目 4 角色画像 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development. Steps use checkbox syntax for tracking.

**Goal:** 引擎按角色发 `role_profile`，适配器映射档次并回报实际 model/vendor/tier；按角色选适配器以启用跨厂商审查；审查发现按严重度 × 置信度分流；按变更的失控成本上限；模拟适配器与一致性套件进 CI。

**Tech Stack:** Python 标准库、Git、unittest；不新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-19-子项目4-角色画像-design.md`（全部，Q1–Q8 已按推荐批准），及 `docs/superpowers/specs/2026-10-12-演进体系-后续子项目.md` §8。
