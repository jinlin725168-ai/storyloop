> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以可核对证据生成 L1，并在任何实现或昂贵产品调用前执行适用入口门禁。

```python
from copy import deepcopy
from tests.routing_support import signals
from storyloop.routing_policy import evaluate, validate_policy

class PolicyTests(unittest.TestCase):
    def test_thresholds_and_guard_are_not_cumulative(self):
        policy = validate_policy(None)
        cases = [(1, "light", False), (4, "heavy", False),
                 (6, "heavy", False), (7, "heavy", True)]
        for stories, tier, split in cases:
            with self.subTest(stories=stories):
                result = evaluate(signals(stories=stories), policy)
                self.assertEqual((result["tier"], result["split"]), (tier, split))
        value = deepcopy(signals())
        value["risks"]["guard"] = "yes"
        self.assertEqual(evaluate(value, policy)["tier"], "standard")
        self.assertEqual(evaluate(value, policy), evaluate(value, policy))
```

```python
TIERS = ("light", "standard", "heavy")
DEFAULT_BUDGETS = {"light": 2, "standard": 3, "heavy": 4}

def max_tier(*tiers: str) -> str:
    if not tiers or any(tier not in TIERS for tier in tiers):
        raise StoryLoopError("Invalid routing tier")
    return max(tiers, key=TIERS.index)
```

计算步骤：先验证完整 Signals 类型和计数（criteria >0，0≤manual≤criteria）；LIGHT 前置条件，否则 standard；应用 STANDARD-FLOOR；HEAVY-SIZE/RISK/MANUAL；SPLIT-SIZE 强制 heavy；最后 GUARD 只升一级。unknown 列入 unresolved；高风险 unknown 留给任务 4/6 阻断，不伪造 yes。人工占比直接比较 `manual / criteria > manual_ratio`，不要四舍五入后比较。

    return not verifiable_goal or (questions >= 2 and
