# 子项目 1：变更性质与判据 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 把引擎的核心不变量从"验收先红后绿"扩展为"判据先于实现确立、按变更性质选择、并能自证有效"，让 fix 与 refactor 两类变更走通闭环。

**Architecture：**
- 合同新增性质与对应字段，校验分两处：结构校验在 `models.py`，语义校验在 `requirement_checklist.py`。
- 验收套件按"行类型决定实现前应有的状态"判定 RED，按 `tier` 分快、重两级执行。
- 新增模块 `oracle_counts.py`：从测试工具的输出里统计执行数，与旧代码基线比较，让判据证明自己真的运行过。
- refactor 复用整条验收套件机制：结构断言就是它的套件。

**Tech Stack：** Python 3.11+ 标准库（`unittest`、`re`、`json`），Git。

**Spec：** `docs/superpowers/specs/2026-10-12-子项目1-变更性质与判据-design.md`；上位文档 `docs/superpowers/specs/2026-10-12-演进体系-design.md`。

## Global Constraints

- 只用 Python 标准库，Python 3.11+；不引入任何第三方运行时依赖。
- 单个函数不超过 50 行，单个文件不超过 500 行；复杂逻辑写清楚"为什么"。
- 测试命令：`.venv/bin/python -m unittest <模块> -v`；全量：`.venv/bin/python -m unittest discover -s tests -t .`（约 10 分钟，放后台）。
- 提交信息：`type(scope): 中文主题`，不加任何 Co-Authored-By 署名行（用户偏好，覆盖默认约定）。
- 旧合同兼容：没有 `nature` 的合同按 `feature` 处理；新增字段全部可选；旧合同的新检查项只给 warning。
- 变更 ID 前缀：`feature` → `FEAT-`，`fix` → `FIX-`，`refactor` → `REF-`；功能分支仍是 `feature/<ID>`。
- 行类型：`positive`、`degradation`、`unknown_state`、`form_parity` 实现前应红；`regression`、`state_preservation`、`non_goal` 实现前应绿。
- 判据类别：`auto-fast`、`auto-heavy`、`manual`；缺省由 `kind` 推出（`automated` → `auto-fast`，`manual` → `manual`）。
- 测试执行数统计不出来时不设门，标记 `uncounted`；执行数为 0，或低于基线且不能由 `test_removals` 解释，判这一层失败。

## Review Focus

1. **测试汇总只出现在 stderr，或输出超过 100k 字符被截断**：执行数必须在截断前、从 stdout 加 stderr 的完整输出中统计（Task 5 的测试固定这一点）。
2. **升级前就在跑的运行（运行状态里没有 `oracle` 字段）续跑**：不能崩溃，只做"执行数为 0"检查，不做基线比较（Task 9 的测试固定这一点）。
3. **Windows 换行（CRLF）的测试输出**：解析器先把 `\r\n` 规范成 `\n`（Task 5 的测试固定这一点）。
4. **从 `ORACLE_DEFECT` 停点执行 `acceptance-repair`**：修复后按新规则重证 RED，运行回到 `IMPLEMENTING`（Task 7 的测试固定这一点）。
5. **多个解析器同时命中**（例如 Maven 输出里夹着 pytest 的汇总）：取执行数最大的，并记录用的是哪个解析器（Task 5 的测试固定这一点）。

```python
def fix_product() -> dict:

    value["nature"] = "fix"

        "observed": "导出少一行", "expected": "导出全部记录",

def refactor_product(subtype: str = "structure") -> dict:
    value = product()
    value["nature"] = "refactor"
    value["refactor"] = {"subtype": subtype, "scope": ["modules/orders/**"],
                         "invariants": ["对外行为不变"], "structural_goals": ["service.py 不再引用 legacy"]}
    if subtype == "dependency-swap":
        value["refactor"]["migration_map"] = [{"from": "legacy.get", "to": "httpx.get",
                                               "assertion": "grep legacy 计数为 0"}]
    return value


class ContractShapeTests(unittest.TestCase):
    def test_contracts_without_a_nature_are_features_and_still_valid(self):
        legacy = product()
        validate_product(legacy)
        self.assertEqual(nature_of(legacy), "feature")

    def test_each_nature_requires_its_own_block(self):
        validate_product(fix_product())
        validate_product(refactor_product())
        validate_product(refactor_product("dependency-swap"))
        missing = fix_product(); del missing["defect"]
        with self.assertRaises(StoryLoopError):
            validate_product(missing)
        stray = product(); stray["defect"] = fix_product()["defect"]
        with self.assertRaises(StoryLoopError):
            validate_product(stray)
        swap = refactor_product("dependency-swap"); del swap["refactor"]["migration_map"]
        with self.assertRaises(StoryLoopError):
            validate_product(swap)
        goalless = refactor_product(); goalless["refactor"]["structural_goals"] = []
        with self.assertRaises(StoryLoopError):
            validate_product(goalless)

    def test_root_causes_are_one_to_five_path_line_locations(self):
        bad = fix_product(); bad["defect"]["root_cause"][0]["location"] = "modules/orders/service.py"
        with self.assertRaises(StoryLoopError):
            validate_product(bad)
        many = fix_product(); many["defect"]["root_cause"] = many["defect"]["root_cause"] * 6
        with self.assertRaises(StoryLoopError):
            validate_product(many)

    def test_criterion_fields_and_consumer_references(self):
        value = product()
        value["consumers"] = [{"id": "C1", "consumer": "导出按钮", "trigger": "点击", "path": "web → api",
                               "in_scope": True, "verification": "接口用例"}]
        value["stories"][0]["acceptance"][0].update({"row_type": "regression", "oracle_class": "auto-heavy",
                                                     "consumers": ["C1"]})
        validate_product(value)
        unknown = deepcopy(value); unknown["stories"][0]["acceptance"][0]["consumers"] = ["C9"]
        with self.assertRaises(StoryLoopError):
            validate_product(unknown)

            validate_product(mismatch)  # kind is automated, class says manual

        self.assertTrue(criterion_expects_red({"kind": "automated", "row_type": "unknown_state"}))

        self.assertEqual(criterion_tier({"kind": "automated", "oracle_class": "auto-heavy"}), "heavy")
        self.assertEqual(criterion_tier({"kind": "manual"}), "manual")
```

```python
NATURES = ("feature", "fix", "refactor")
ROW_TYPES = ("positive", "degradation", "unknown_state", "form_parity",
             "regression", "state_preservation", "non_goal")
# Rows that assert new or changed behaviour must fail before implementation; the rest assert what
# must keep holding (or must not be claimed) and must already pass on the old code.
RED_ROWS = frozenset({"positive", "degradation", "unknown_state", "form_parity"})
ORACLE_CLASSES = ("auto-fast", "auto-heavy", "manual")
LOCATION = re.compile(r"^[^:\s][^:]*:[1-9][0-9]*$")


def nature_of(product: dict) -> str:
    return product.get("nature", "feature")


def criterion_expects_red(criterion: dict) -> bool:
    return criterion.get("row_type", "positive") in RED_ROWS


def criterion_tier(criterion: dict) -> str:
    """fast | heavy | manual, from `oracle_class` or, when absent, from `kind`."""
    default = "manual" if criterion.get("kind") == "manual" else "auto-fast"
    oracle_class = criterion.get("oracle_class", default)
    return {"auto-fast": "fast", "auto-heavy": "heavy", "manual": "manual"}[oracle_class]
```

```python
def _acceptance(value: object, seen: set, consumers: set) -> None:
    require(isinstance(value, list) and bool(value), "Story needs acceptance criteria")
    for criterion in value:
        fields(criterion, {"id", "given", "when", "then", "kind"},
               {"row_type", "oracle_class", "consumers", "reproduces_defect"})
        key = identifier(criterion["id"], "criterion id")
        require(key not in seen, "Duplicate acceptance id")
        seen.add(key)
        for part in ("given", "when", "then"):
            text(criterion[part], part)
        require(criterion["kind"] in {"automated", "manual"}, "Invalid acceptance kind")
        _criterion_extras(criterion, consumers)


def _criterion_extras(criterion: dict, consumers: set) -> None:
    require(criterion.get("row_type", "positive") in ROW_TYPES, "Invalid acceptance row_type")
    if "oracle_class" in criterion:
        require(criterion["oracle_class"] in ORACLE_CLASSES, "Invalid acceptance oracle_class")
        require((criterion["oracle_class"] == "manual") == (criterion["kind"] == "manual"),
                "oracle_class must be manual exactly when kind is manual")
    if "consumers" in criterion:
        strings(criterion["consumers"], "criterion consumers")
        require(set(criterion["consumers"]) <= consumers, "Criterion references an unknown consumer")
    if "reproduces_defect" in criterion:
        require(isinstance(criterion["reproduces_defect"], bool), "reproduces_defect must be a boolean")
        require(not criterion["reproduces_defect"] or criterion_expects_red(criterion),
                "A defect reproduction must be a must-be-red row")
```

把 `validate_product` 换成（`_story` 只改一行：`_acceptance(story["acceptance"], criteria, consumers)`，并给 `_story` 增加 `consumers: set` 参数）：

```python
def validate_product(value: object) -> dict:
    """Validate stories, business outcomes, global IDs, ordered dependencies and the nature blocks."""
    fields(value, {"version", "goal", "non_goals", "questions", "stories"},
           {"capability", "clarifications", "nature", "defect", "refactor", "consumers",
            "coverage_exemptions", "test_removals"})
    require(value["version"] == 1, "Unsupported product version")
    text(value["goal"], "goal")
    strings(value["non_goals"], "non_goals")
    _questions(value["questions"])
    if "capability" in value:
        identifier(value["capability"], "capability")
    if "clarifications" in value:
        _clarifications(value["clarifications"])
    _nature_blocks(value)
    consumers = _consumers(value.get("consumers", []))
    _exemptions(value.get("coverage_exemptions", []))
    _removals(value.get("test_removals", []))
    require(isinstance(value["stories"], list), "stories must be a list")
    seen, criteria = set(), set()
    for story in value["stories"]:
        _story(story, seen, criteria, consumers)
    return value


def _nature_blocks(value: dict) -> None:
    nature = value.get("nature", "feature")
    require(nature in NATURES, "nature must be feature, fix or refactor")
    require(("defect" in value) == (nature == "fix"), "A fix needs a defect block; other natures have none")
    require(("refactor" in value) == (nature == "refactor"),
            "A refactor needs a refactor block; other natures have none")
    if nature == "fix":
        _defect(value["defect"])
    if nature == "refactor":
        _refactor(value["refactor"])


def _defect(value: object) -> None:
    fields(value, {"observed", "expected", "reproduction", "root_cause", "confirmed", "unconfirmed"},
           {"reporter_hypothesis", "sibling_entries", "origin_change"})
    for key in ("observed", "expected"):
        text(value[key], key)
    require(bool(strings(value["reproduction"], "reproduction")), "reproduction needs steps")
    require(isinstance(value["root_cause"], list) and 1 <= len(value["root_cause"]) <= 5,
            "root_cause needs one to five statements")
    for cause in value["root_cause"]:
        fields(cause, {"statement", "location"})
        text(cause["statement"], "root cause statement")
        require(isinstance(cause["location"], str) and LOCATION.fullmatch(cause["location"]) is not None,
                "root cause location must be path:line")
    strings(value["confirmed"], "confirmed")
    strings(value["unconfirmed"], "unconfirmed")
    if "reporter_hypothesis" in value:
        text(value["reporter_hypothesis"], "reporter_hypothesis")
    if "sibling_entries" in value:
        strings(value["sibling_entries"], "sibling_entries")
    if "origin_change" in value:
        identifier(value["origin_change"], "origin change")


def _refactor(value: object) -> None:
    fields(value, {"subtype", "scope", "invariants", "structural_goals"}, {"migration_map"})
    require(value["subtype"] in {"structure", "dependency-swap"}, "Invalid refactor subtype")
    require(bool(strings(value["scope"], "refactor scope")), "refactor scope is empty")
    strings(value["invariants"], "invariants")
    require(bool(strings(value["structural_goals"], "structural_goals")),
            "A refactor needs at least one assertable structural goal")
    if value["subtype"] == "dependency-swap":
        require(isinstance(value.get("migration_map"), list) and bool(value["migration_map"]),
                "A dependency swap needs a migration map")
    for entry in value.get("migration_map", []):
        fields(entry, {"from", "to", "assertion"})
        for key in ("from", "to", "assertion"):
            text(entry[key], f"migration {key}")


def _consumers(value: object) -> set:
    require(isinstance(value, list), "consumers must be a list")
    seen: set = set()
    for item in value:
        fields(item, {"id", "consumer", "trigger", "path", "in_scope", "verification"})
        key = identifier(item["id"], "consumer id")
        require(key not in seen, "Duplicate consumer id")
        seen.add(key)
        for field in ("consumer", "trigger", "path", "verification"):
            text(item[field], field)
        require(isinstance(item["in_scope"], bool), "in_scope must be a boolean")
    return seen


def _exemptions(value: object) -> None:
    require(isinstance(value, list), "coverage_exemptions must be a list")
    rows = [item.get("row_type") for item in value if isinstance(item, dict)]
    require(len(rows) == len(set(rows)), "Duplicate coverage exemption")
    for item in value:
        fields(item, {"row_type", "reason"})
        require(item["row_type"] in ROW_TYPES, "Invalid exemption row_type")
        text(item["reason"], "exemption reason")


def _removals(value: object) -> None:
    require(isinstance(value, list), "test_removals must be a list")
    for item in value:
        fields(item, {"path", "reason"})
        text(item["path"], "removed test path")
        text(item["reason"], "removal reason")
```

```python
def _nature_items(add, product: dict, project: Path | None) -> None:
    """Checks that follow from the change's nature; legacy contracts (no nature) only get warnings."""
    nature = nature_of(product)
    strict = "nature" in product
    criteria = [c for story in product.get("stories") or [] for c in story.get("acceptance") or []]
    automated = [c for c in criteria if c.get("kind") == "automated"]
    if nature in {"feature", "fix"}:
        add("Coverage", "error" if strict and not any(criterion_expects_red(c) for c in automated) else "ok",
            "At least one automated criterion asserts new behaviour (must be red before implementation)")
        _row_coverage(add, product, criteria, "error" if strict else "warning")
    if nature == "fix":
        _fix_items(add, product, automated, project)
    if nature == "refactor":
        _refactor_items(add, product, automated, project)
    _consumer_items(add, product, criteria, "error" if strict else "warning")
    named = [c["id"] for c in criteria if IDENTIFIER_LIKE.search(" ".join(
        str(c.get(part, "")) for part in ("given", "when", "then")))]
    add("Clarity", "warning" if named else "ok",
        "Criteria describe observable behaviour, not class or function names"
        + (f" (check: {', '.join(named[:3])})" if named else ""))


def _row_coverage(add, product: dict, criteria: list, level: str) -> None:
    present = {c.get("row_type", "positive") for c in criteria}
    exempt = {item["row_type"] for item in product.get("coverage_exemptions") or []}
    for row in ROW_TYPES:
        add("Coverage", level if row not in present | exempt else "ok",
            f"Row type {row} has a criterion or a stated exemption")


def _fix_items(add, product: dict, automated: list, project: Path | None) -> None:
    defect = product["defect"]
    add("Coverage", "ok" if any(c.get("reproduces_defect") for c in automated) else "error",
        "An automated criterion reproduces the defect")
    for cause in defect["root_cause"]:
        found = project is None or _location_exists(project, cause["location"])
        add("Traceability", "ok" if found else "error",
            f"root cause location exists at the base: {cause['location']}")
    hypothesis = defect.get("reporter_hypothesis", "").strip()
    rules = " ".join(rule for story in product["stories"] for rule in story["rules"])
    add("Clarity", "warning" if hypothesis and hypothesis in rules else "ok",
        "The reporter's hypothesis is not copied into the rules as a requirement")


def _refactor_items(add, product: dict, automated: list, project: Path | None) -> None:
    goals = product["refactor"]["structural_goals"]
    red = [c for c in automated if criterion_expects_red(c)]
    add("Coverage", "ok" if len(red) >= len(goals) else "error",
        f"Every structural goal has an automated criterion ({len(red)} for {len(goals)} goals)")
    if project is not None:
        from .baseline import load_project_config  # local import keeps the checklist usable without a project
        profile = load_project_config(project)["profile"]
        configured = bool(profile.get("test_roots")) and bool(profile.get("unit_commands") or profile.get("test_commands"))
        add("Feasibility", "ok" if configured else "error",
            "A refactor's characterization gate is configured (test_roots and unit_commands)")


def _consumer_items(add, product: dict, criteria: list, level: str) -> None:
    covered = {consumer for c in criteria for consumer in c.get("consumers") or []}
    for consumer in product.get("consumers") or []:
        if consumer["in_scope"]:
            add("Coverage", level if consumer["id"] not in covered else "ok",
                f"In-scope consumer {consumer['id']} is covered by a criterion")


def _location_exists(project: Path, location: str) -> bool:
    """`path:line` names an existing line of a file at the locked base commit."""
    from .baseline import _git, load_baseline
    path, line = location.rsplit(":", 1)
    try:
        content = _git(project, "show", f"{load_baseline(project)['source_head']}:{path}")
    except Exception:  # noqa: BLE001  git reports a missing path through a non-zero exit
        return False
    return 1 <= int(line) <= max(len(content.splitlines()), 1)
```

```python
"""How many tests really ran: parsed from the runners' own summaries.

An oracle must prove it ran. A runner can exit 0 having executed nothing (a discovery rule that
stopped matching, an incompatible test platform), which looks green. Counting executed tests and
comparing them with the old code's baseline turns that silent hole into a failure. Output that no
parser recognizes stays uncounted (None) and is reported as such, never treated as zero.
"""

from __future__ import annotations

from pathlib import Path
import re

from .models import StoryLoopError, require


def _last(pattern: str, text: str):
    matches = list(re.finditer(pattern, text, re.M))
    return matches[-1] if matches else None


def _words(fragment: str) -> dict[str, int]:
    return {word: int(count) for count, word in re.findall(r"(\d+) (\w+)", fragment)}


def _unittest(text: str) -> dict | None:
    ran = _last(r"^Ran (\d+) tests? in ", text)
    if not ran:
        return None
    tail = _last(r"^(?:OK|FAILED)\b(.*)$", text)
    extra = tail.group(1) if tail else ""
    failed = sum(int(n) for n in re.findall(r"(?:failures|errors)=(\d+)", extra))
    skipped = re.search(r"skipped=(\d+)", extra)
    skip = int(skipped.group(1)) if skipped else 0
    return {"executed": int(ran.group(1)) - skip, "failed": failed, "skipped": skip}


def _pytest(text: str) -> dict | None:
    line = _last(r"^=+ (.*?) in [\d.]+s(?: \([^)]*\))? =+$", text)
    if not line:
        return None
    words = _words(line.group(1))
    failed = words.get("failed", 0) + words.get("error", 0) + words.get("errors", 0)
    executed = words.get("passed", 0) + failed + words.get("xfailed", 0) + words.get("xpassed", 0)
    return {"executed": executed, "failed": failed, "skipped": words.get("skipped", 0)}


def _maven(text: str) -> dict | None:
    line = _last(r"Tests run: (\d+), Failures: (\d+), Errors: (\d+), Skipped: (\d+)", text)
    if not line:
        return None
    run, failures, errors, skipped = (int(group) for group in line.groups())
    return {"executed": run - skipped, "failed": failures + errors, "skipped": skipped}


def _gradle(text: str) -> dict | None:
    line = _last(r"(\d+) tests? completed(?:, (\d+) failed)?(?:, (\d+) skipped)?", text)
    if not line:
        return None
    total, failed, skipped = (int(group or 0) for group in line.groups())
    return {"executed": total - skipped, "failed": failed, "skipped": skipped}


def _jest(text: str) -> dict | None:
    line = _last(r"^Tests:\s+(.*?)(\d+) total", text)
    if not line:
        return None
    words, total = _words(line.group(1)), int(line.group(2))
    skipped = words.get("skipped", 0) + words.get("todo", 0)
    return {"executed": total - skipped, "failed": words.get("failed", 0), "skipped": skipped}


def _vitest(text: str) -> dict | None:
    line = _last(r"^\s*Tests\s+(.*?)\((\d+)\)\s*$", text)
    if not line:
        return None
    words, total = _words(line.group(1)), int(line.group(2))
    skipped = words.get("skipped", 0) + words.get("todo", 0)
    return {"executed": total - skipped, "failed": words.get("failed", 0), "skipped": skipped}


def _go(text: str) -> dict | None:
    marks = re.findall(r"^\s*--- (PASS|FAIL|SKIP):", text, re.M)
    if not marks:
        return None
    return {"executed": marks.count("PASS") + marks.count("FAIL"), "failed": marks.count("FAIL"),
            "skipped": marks.count("SKIP")}


PARSERS = (("maven", _maven), ("gradle", _gradle), ("pytest", _pytest), ("unittest", _unittest),
           ("jest", _jest), ("vitest", _vitest), ("go", _go))
UNCOUNTED = {"executed": None, "failed": None, "skipped": None, "parser": None}


def count_tests(command: list[str], output: str, patterns: list[dict] | None = None) -> dict:
    """Executed/failed/skipped from a runner's full output; a project pattern wins for its command."""
    text = output.replace("\r\n", "\n")
    joined = " ".join(command)
    for item in patterns or []:
        if item["match"] in joined:
            match = _last(item["executed"], text)
            if match:
                return {"executed": int(match.group("executed")), "failed": None, "skipped": None,
                        "parser": "custom"}
    found = [(name, result) for name, parse in PARSERS if (result := parse(text)) is not None]
    if not found:
        return dict(UNCOUNTED)
    name, best = max(found, key=lambda pair: pair[1]["executed"])
    return {**best, "parser": name}


def validate_patterns(value: object) -> list[dict]:
    """settings `test_count_patterns`: [{match, executed}] where `executed` has a named group."""
    require(isinstance(value, list), "test_count_patterns must be a list")
    result = []
    for item in value:
        require(isinstance(item, dict) and set(item) == {"match", "executed"},
                "Each test count pattern needs exactly match and executed")
        require(isinstance(item["match"], str) and bool(item["match"]), "pattern match must be nonempty text")
        try:
            compiled = re.compile(item["executed"], re.M)
        except (TypeError, re.error) as exc:
            raise StoryLoopError(f"Invalid test count pattern: {exc}") from None
        require("executed" in compiled.groupindex, "A test count pattern needs a named group 'executed'")
        result.append({"match": item["match"], "executed": item["executed"]})
    return result
```

```python
def _validate_manifest(manifest: object, change: dict) -> dict:
    fields(manifest, {"version", "tests"})
    require(manifest["version"] == 1 and isinstance(manifest["tests"], list)
            and bool(manifest["tests"]), "Smoke manifest needs tests")
    automated = {
        criterion["id"]: criterion
        for story in change["product"]["stories"]
        for criterion in story["acceptance"] if criterion["kind"] == "automated"
    }
    seen: set[str] = set()
    covered: set[str] = set()
    for test in manifest["tests"]:
        _validate_manifest_test(test, automated, seen)
        covered.update(test["criteria"])
    require(set(automated) <= covered, "Automated acceptance criteria are uncovered")
    return manifest


def _validate_manifest_test(test: dict, automated: dict, seen: set) -> None:
    fields(test, {"id", "criteria", "command", "timeout_seconds"}, {"tier"})
    test_id = identifier(test["id"], "smoke test id")
    require(test_id not in seen, "Duplicate smoke test id")
    seen.add(test_id)
    require(isinstance(test["criteria"], list)
            and all(isinstance(item, str) for item in test["criteria"]),
            "Smoke criteria must be a list")
    require(set(test["criteria"]) <= set(automated), "Smoke test references unknown criterion")
    tier = test.get("tier", "fast")
    require(tier in {"fast", "heavy"}, "Smoke test tier must be fast or heavy")
    criteria = [automated[item] for item in test["criteria"]]
    require(len({criterion_expects_red(c) for c in criteria}) <= 1,
            "One test cannot mix criteria with different expected pre-implementation states")
    require(all(criterion_tier(c) == tier for c in criteria),
            "A test's tier must match its criteria's oracle_class (auto-fast → fast, auto-heavy → heavy)")
    command = test["command"]
    require(isinstance(command, list) and bool(command),
            "Smoke command must be a nonempty argv array")
    require(len(command) <= 100 and all(isinstance(arg, str) and bool(arg) for arg in command),
            "Smoke command argv is invalid")
    require(type(test["timeout_seconds"]) is int
            and 1 <= test["timeout_seconds"] <= 3600, "Invalid smoke timeout")
```

```python
def _judge_red(results: list[dict], manifest: dict, change: dict) -> None:
    """RED by row type: new-behaviour rows must fail, kept-behaviour rows must already pass.

    Only fast tests decide (heavy ones are recorded, not judged). A failure that executed zero tests
    is a collection or import error, not a behaviour failure, so it never counts as RED.
    """
    tiers = {test["id"]: test.get("tier", "fast") for test in manifest["tests"]}
    fast = [item for item in results if tiers[item["id"]] == "fast"]
    broken = [item for item in fast if item["status"] == "ERROR" or (
        item["status"] == "FAIL" and (item.get("counts") or {}).get("executed") == 0)]
    require(not broken, "Smoke RED proof encountered an environment error")
    expects_red = {criterion["id"]: criterion_expects_red(criterion)
                   for story in change["product"]["stories"] for criterion in story["acceptance"]}
    failed = {criterion for item in fast if item["status"] == "FAIL" for criterion in item["criteria"]}
    covered = {criterion for item in fast for criterion in item["criteria"]}
    tails = [_tail(item) for item in results]
    must_hold = sorted(c for c in covered if not expects_red[c] and c in failed)
    if must_hold:
        raise StoryLoopError(
            "Criteria that must already hold fail on the code before implementation: "
            + ", ".join(must_hold) + " (the tests are wrong, not the code)",
            code="ORACLE_DEFECT", details={"criteria_failing": must_hold, "results": tails})
    green = sorted(c for c in covered if expects_red[c] and c not in failed)
    if green:
        raise StoryLoopError(
            "Acceptance suite is already green before implementation and did not prove RED"
            + f" (criteria passing: {', '.join(green)})",
            code="EXISTING_GREEN", details={"criteria_green": green, "results": tails})
```

```python
def _run_tiered(project: Path, tests: list[dict], patterns: list[dict], run_all: bool) -> list[dict]:
    """Fast tests first; heavy ones only once every fast test passed (always, when proving RED)."""
    fast = [test for test in tests if test.get("tier", "fast") == "fast"]
    heavy = [test for test in tests if test.get("tier", "fast") == "heavy"]
    results = {test["id"]: {**_run_test(project, test, patterns), "tier": "fast"} for test in fast}
    go = run_all or all(item["status"] == "PASS" for item in results.values())
    for test in heavy:
        results[test["id"]] = ({**_run_test(project, test, patterns), "tier": "heavy"} if go
                               else _not_run(test))
    return [results[test["id"]] for test in tests]


def _not_run(test: dict) -> dict:
    return {"id": test["id"], "criteria": list(test["criteria"]), "command": list(test["command"]),
            "status": "NOT_RUN", "reason": "fast oracle did not pass", "returncode": None,
            "timed_out": False, "tier": "heavy",
            "counts": {"executed": None, "failed": None, "skipped": None, "parser": None},
            "stdout": "", "stderr": ""}
```

```python
COUNTED_LAYERS = ("unit", "integration", "acceptance", "smoke")
BASELINE_LAYERS = ("unit", "integration")


def executed_list(layer: dict) -> list:
    return [(item.get("counts") or {}).get("executed") for item in layer.get("results") or []]


def sample_baseline(project: Path, config: dict) -> dict:
    """Executed counts of the unit and integration commands on the code before implementation."""
    from .project_profile import layer_commands
    from .smoke_runner import run_commands_isolated
    profile, timeout = config["profile"], config["check_timeout_seconds"]
    baseline = {}
    for name in BASELINE_LAYERS:
        commands = layer_commands(profile, name)
        baseline[name] = executed_list(run_commands_isolated(project, commands, timeout)) if commands else []
    return baseline


def removals_explained(project: Path, product: dict) -> bool:
    """A drop in executed tests is explained only when every declared removal really happened."""
    removals = product.get("test_removals") or []
    return bool(removals) and all(not (Path(project) / item["path"]).exists() for item in removals)


def check_layers(layers: dict, oracle: dict | None, explained: bool) -> dict:
    """Fail a green layer that executed nothing, or fewer tests than its baseline without explanation."""
    baseline = (oracle or {}).get("baseline") or {}
    checked = dict(layers)
    for name in COUNTED_LAYERS:
        if name in layers:
            checked[name] = _check_layer(layers[name], baseline.get(name), explained)
    return checked


def _check_layer(layer: dict, baseline: list | None, explained: bool) -> dict:
    results = layer.get("results") or []
    uncounted = [item["id"] for item in results if (item.get("counts") or {}).get("executed") is None]
    out = {**layer, "uncounted": uncounted}
    if layer.get("status") != "PASSED":
        return out
    problems = []
    for index, item in enumerate(results):
        executed = (item.get("counts") or {}).get("executed")
        if executed is None:
            continue
        if executed == 0:
            problems.append(f"{item['id']}: 执行数为 0")
        before = baseline[index] if baseline and index < len(baseline) else None
        if before is not None and executed < before and not explained:
            problems.append(f"{item['id']}: 执行数从 {before} 降到 {executed}")
    if problems:
        out.update({"status": "FAILED", "oracle_problems": problems})
    return out
```

```markdown
# 判据写法

判据在实现之前写好，实现者改不了；它必须能证明自己真的运行过、真的有约束力。

## 适用角色

- product：给每条验收条件标 `row_type` 与 `oracle_class`，覆盖七个行类型或写明豁免理由；写消费端矩阵；fix 先追调用链再写根因（每条带 `path:line`），把报告者的猜测单列；refactor 写可断言的结构目标。
- acceptance：按 `references/acceptance-matrix.md` 写用例；refactor 按 `references/structural-assertions.md` 写结构断言；为每个测试标 `tier`。
- characterize：按 `references/characterization.md` 锁定现有行为。
- review：检查弱断言（只断言存在、非空）、被删除的测试、用 mock 顶替的集成判据。

## 执行器退出码

- 0：全部通过
- 1：行为断言失败（只有这个算 RED）
- 2：环境错误：收集失败、导入错误、夹具错误、依赖起不来

测试工具的汇总行（例如 `Ran N tests`、`N passed`）要保留在输出里，引擎靠它统计执行数。
```

```markdown
| degradation | 红 | 依赖失败时明确失败、主流程不受影响 | 依赖挂了静默返回空列表 |
| unknown_state | 红 | 加载中或读取失败时不等同于否定（"未知不等于不支持"） | 元数据没加载完就判"不支持" |
| form_parity | 红 | 同一能力的不同用法都覆盖（独立应用与工作流节点） | 只测了一种入口 |
| regression | 绿 | 既有契约不变（字段、格式、校验） | 为了让新字段通过放宽了旧校验 |
| state_preservation | 绿 | 已保存状态"载入 → 交互 → 保存"后，除目标字段外完全相等 | 只断言新字段，没比对其余字段 |
| non_goal | 绿 | 没做的事不被宣称为已支持 | 报告里写"支持按工具统计"而其实没做 |

规则：

- 一个测试只覆盖同一种"实现前状态"的条件：应红的和应绿的分开写。
- `oracle_class: auto-heavy` 的条件写进 `tier: heavy` 的测试（端到端、浏览器、长时间）；其余写进 `tier: fast`。
- 断言值本身，不只断言字段存在或非空。
- 集成判据用真实依赖，不用 mock 顶替。
```

```python
def _oracle_view(layers: dict, oracle: dict | None, skills_used: dict | None) -> dict:
    """Did each oracle prove it ran: executed counts per command against the old code's baseline."""
    counts = {name: [{"id": item.get("id"), **(item.get("counts") or {})}
                     for item in (layers.get(name) or {}).get("results") or []]
              for name in ("unit", "integration", "acceptance", "smoke")}
    uncounted = sorted({f"{name}:{item}" for name in counts
                        for item in (layers.get(name) or {}).get("uncounted") or []})
    return {"baseline": (oracle or {}).get("baseline") or {}, "executed": counts, "uncounted": uncounted,
            "skills_used": dict(skills_used or {})}


def _oracle_markdown(view: dict) -> list[str]:
    lines = ["", "## 判据自证", "", "| 层 | 命令 / 用例 | 执行数 | 基线 | 解析器 |", "|---|---|---|---|---|"]
    for name, items in view["executed"].items():
        baseline = view["baseline"].get(name) or []
        for index, item in enumerate(items):
            before = baseline[index] if index < len(baseline) else "-"
            executed = "未能统计" if item.get("executed") is None else item["executed"]
            lines.append(f"| {name} | {_markdown(item.get('id'))} | {executed} | {before} | "
                         f"{item.get('parser') or '-'} |")
    if view["uncounted"]:
        lines += ["", "未能统计执行数（这些命令没有自证）：" + ", ".join(view["uncounted"])]
    skills = ", ".join(f"{name} {version}" for name, version in sorted(view["skills_used"].items()))
    lines += ["", f"使用的技能包：{skills or '-'}"]
    return lines
```
