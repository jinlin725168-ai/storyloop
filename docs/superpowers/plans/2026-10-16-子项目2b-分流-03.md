# 2b 任务 9–12：升档与交付 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成实现中升档的安全恢复，并提供可用命令、兼容回归和真实验收证据。

**Architecture:** 边界检查之后、质量检查之前检查范围漂移；规划状态单独持久化。CLI 只转发引擎操作，审批不会由交互回答隐式生成。

**Tech Stack:** Python 标准库、unittest、Git 临时仓库及现有代理适配器。

**Spec:** [2b 设计](../specs/2026-10-16-子项目2b-分流-design.md) §6–11。

## Global Constraints

- 继承[总计划](2026-10-16-子项目2b-分流.md)全部约束、数据和前置接口。
- 不放宽权限、受保护文件和 Git 可见性检查；规划不计质量失败，不退还已判定实现轮次。
- 不以模拟冒充真实代理/审批，不修改或删除原有真实项目数据。

```python
def scope_expanded(planned: dict, actual: dict) -> bool:
    if actual.get("unknown_fields"):
        return True
    return any(set(actual.get(key, [])) - set(planned.get(key, []))
               for key in ("touched", "creates", "interfaces"))
```

- [ ] L3 将实际路径量测与已保存角色/人类风险 yes 合并；新风险事实必须有受检位置，不能仅靠未校验自由文本。恢复时只用 frozen policy；candidate_digest 纳入审批绑定。same-tier expansion 也更新计划，拆分阈值命中先停 SPLIT_RECOMMENDED。实际路径完全未扩展且没有新的风险事实时，保留已验证方案的接口证据；新路径的接口未知只触发一次补证。重规划后将验证过的实际范围/证据写入 scope，按 candidate_digest 记已处理标记，不能每次把接口未知重新当成零或无限重规划。
- [ ] 执行过且可判定的 implement 本轮只计一次；重规划不调用 record_failure、不更新 NO_PROGRESS signature。持久化 `planning={origin:"L3", phase:"REPLAN", consumed_attempt:N, candidate_digest:...}`；停点恢复从 N+1 实现，重入规划不增加 N。
- [ ] 原 for/range 改成每轮重新解析限额的 while，比较 `state["attempt"] < limit`；AGENT_UNAVAILABLE 继续现有归还机制。light 第 2 次升 heavy 默认限额可变 4；显式限额 2 则预算耗尽，不自动赠送轮次。
- [ ] 对未锁定既有路径，在恢复前将路径、内容摘要和恢复原因记录于控制目录（不复制源文件正文到日志），只恢复这些路径到 contract_commit，再 characterize。其余候选保持；丢弃的业务修改由下一轮 implement 重做。用 phase 标记先保存清单和来源、再恢复、再记录完成，崩溃恢复复核路径指纹，不能误覆盖用户新增改动。新文件不需要伪造已有特征锁。
- [ ] 固定顺序为：保存恢复清单→恢复未锁路径→L2 方案→方案审批→一致性→characterize→implement。重规划 design 只读且能看到 retained candidate 与被恢复路径说明。L3 审批使用恢复后的 implementation_digest；characterize 产生受保护锁工件后重算 binding，若 implementation_digest 或 suite_digest 改变，回到方案审批一次，不沿用旧批准。重入时已完成且摘要匹配的 characterization 不重复执行，保证不会形成审批/补锁无限循环。
- [ ] reset 在 WORKSPACE_TAINTED 的规划中断恢复原规划阶段，不减已消费轮次。不得扩大 RESETTABLE 来绕过审批；规划恢复通过 run/replan。BASE/判据/输入漂移在任何 DONE 快速路径之前检查。
- [ ] 测试：第一次 L3 标准升重并停审；第二次恢复不重复升档/消费；同档范围扩展；新增越界文件先失败；guard重入；限额2→4与显式2；NO_PROGRESS不污染；恢复后其它候选字节相同；每个 phase 崩溃重入；用户修改冲突拒绝覆盖；legacy 未锁路径行为不变。
