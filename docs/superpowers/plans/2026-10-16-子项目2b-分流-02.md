```python
def resolve_budget(config: dict, tier: str, *, legacy: bool = False) -> dict:
    if "max_attempts" in config:
        value = config["max_attempts"]
        require(type(value) is int and value > 0, "Invalid max_attempts")
        return {"limit": value, "source": "explicit"}
    if legacy:
        return {"limit": 3, "source": "legacy"}
    require(tier in DEFAULT_BUDGETS, "Invalid routing tier")
    return {"limit": DEFAULT_BUDGETS[tier], "source": "tier"}
```

DEFAULT_BUDGETS 从任务 1 导入，require 从 models 导入。bootstrap 不再主动写 max_attempts=3；用户 overrides 显式值保留。现有读取 config[max_attempts] 的地方统一传递解析后的运行 config，不能只改 loop 而遗漏 implement payload。

```python
def consistency_status(findings: list[dict]) -> str:
    targets = {item["target"] for item in findings if item["blocking"]}
    for target, status in (("contract", "NEEDS_SPEC_FIX"),
                           ("oracle", "ORACLE_DEFECT"),
                           ("design", "DESIGN_REVISION_REQUIRED")):
        if target in targets:
            return status
    return "COHERENT"
```
