# 架构收敛阶段 E1 验证

## 范围

本批交付 base 合同与人工实现通道。评审修订 PR #40 决定：回归使用全部已配置的 unit/integration/checks；`base_build_commands` 必须声明，空列表表示无构建步骤；人工批准合同后直接进入人工实现停点。代理实现、跨厂商审查、判据路径先红归 E2，功能变更 `blocked_by` 衔接归 E3；I13 仍待完整交付。

## 守护注入

- G1：改写旧底座证据的合同摘要或批准命令摘要，`guard_g1` 拒绝；撤除后旧底座绿证据通过。
- G2：审查后改写 BASE 提案的路径类别，使 foundation scope 含 upstream 路径，`guard_g2` 拒绝；撤除后精确路径和候选证据通过。
- 独立审查：把审查者改成候选提交者，恢复运行被拒；具名另一人记录后进入固定人工验收。
- FINALIZING：在写入 `baseline.json` 后注入中断，重试采用同一回执且版本只加一次；在报告回执提交后重试采用原提交。
- 非 base 底座路径、控制面路径、未批准额外提交及错误 scope 分别由现有边界守护与 `test_base_lifecycle` 的临时仓库样本拒绝。
- 架构：临时让 `run_guards` 导入可变区 `base_execution`，架构测试报一条 `upward/base_imports_mutable` 违规及新增环；撤销该导入后 32 个架构测试全绿，豁免仍为 0。

## 人工通道实跑

在 `/tmp/storyloop-e1-demo` 初始化的独立样本中，以下命令按顺序执行（输出只列决定性字段）：

```text
storyloop base-propose /tmp/storyloop-e1-demo --path pom.xml --reason '更新构建配置' --json
  status=PROPOSED, change_id=BASE-20261024-001
storyloop approve /tmp/storyloop-e1-demo --change BASE-20261024-001 --no-interactive --json
  status=APPROVED, tier=heavy, baseline_version=1.0.0
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --implementer human --json
  status=HUMAN_IMPLEMENTATION_REQUIRED, branch=storyloop/BASE-20261024-001
git add pom.xml; git commit -m 'build: 人工更新底座配置'
  commit=22f541b
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --json
  status=IMPLEMENTING
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --json
  status=BASE_REVIEW_REQUIRED
storyloop base-review /tmp/storyloop-e1-demo --change BASE-20261024-001 --verdict pass --note '已核对构建配置与批准路径' --json
  status=REVIEW_RECORDED, reviewer=Independent Reviewer
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --json
  status=MANUAL_ACCEPTANCE_REQUIRED, pending=[BASE-ACCEPT]
storyloop accept /tmp/storyloop-e1-demo --change BASE-20261024-001 --criterion BASE-ACCEPT --note '批准目标和路径已满足' --json
  status=ACCEPTED
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --json
  status=FINALIZING, integration_commit=4c0437b
storyloop run /tmp/storyloop-e1-demo --change BASE-20261024-001 --json
  status=PASSED
python -c "from storyloop.baseline import load_baseline; print(load_baseline('/tmp/storyloop-e1-demo')['baseline_version'])"
  1.0.1
```

首次实跑在 `BASE_REVIEW_REQUIRED → MANUAL_ACCEPTANCE_REQUIRED` 暴露遗漏的合法迁移；先补失败测试再修状态表，随后同一运行恢复并完成，未重建样本或改写提交。
