## 命令与关键输出

以下 `$PROJECT` 指上述临时项目；`$PROOF` 是人写的 JSON，声明 `criterion_paths=[acceptance/smoke/manifest.json, acceptance/smoke/check_coordinates.py]`、`check_ref={kind:system_smoke,id:coordinates}`、`violation_path=pom.xml`。所有 StoryLoop 命令均加了 `--json`。

```text
storyloop base-propose $PROJECT --path pom.xml --path acceptance/smoke/manifest.json --path acceptance/smoke/check_coordinates.py --reason 更新坐标 --proof-file $PROOF
→ PROPOSED BASE-20261029-001
storyloop approve $PROJECT --change BASE-20261029-001 --no-interactive
→ APPROVED
storyloop adapters check $PROJECT

storyloop run $PROJECT --change BASE-20261029-001 --implementer agent
→ DESIGN_APPROVAL_REQUIRED
storyloop base-design-approve $PROJECT --change BASE-20261029-001 --plan-id 134934491592f9b5364f1c41628f710a13920fde3d99e38930066f9a66bf3995
→ DESIGN_APPROVED
storyloop run $PROJECT --change BASE-20261029-001
→ IMPLEMENTING
storyloop run $PROJECT --change BASE-20261029-001
→ BASE_REVIEW_REQUIRED
storyloop run $PROJECT --change BASE-20261029-001
```

| Git 对象 | OID |

| 源提交的旧 `pom.xml` blob | `1304e0cce24a2510f1788d133559310d452e32c9` |

## 限制

脚本适配器只验证 StoryLoop 通道，不代表真实模型效果。此试用的 `pom.xml` 是坐标文本样本，没有运行 Maven；构建配置明确声明无构建命令。强制目标证明仅适用于本次修改判据路径的 base 合同；其他 base 仍依人工验收。
