## 交付与信任边界

两阶段入口 `init --scaffold [--stack …]` 生成执行器、AGENT_GUIDE、settings 草案及 onboarding.json；保持原 init 签名和旧 vendored/`{python}` 行为。生成阶段不写 baseline/config/exclude、不提交、不执行栈命令或安装依赖。人工补全并提交后，init 与后续 BASE 均校验版本、hook、配置及保护范围；初始化独占锁和归属写入 journal 在故障时只回滚本次仍匹配的内容。

`{storyloop_harness}` 首 argv 由引擎转为受信解释器 `-I -B`、绝对 launcher。受保护 case 在可信 TestResult 中计数，候选业务仅在独立子进程；不将业务 stdout、可写 JSON 或提前退出当作执行证据。新 helper 使用私有 scratch、内容同步、显式依赖缓存、HTTP 预期状态、登记服务和 finally 进程树清理。行为断言失败 1；环境/协议/导入/清理错误及零执行 2；实际执行全绿 0。

使用方法及实际运行过的例子见[版本化冒烟执行器](../smoke-harness.md)。helper 是标准库实现，没有新增依赖、发布版本或数据库/鉴权功能。只内置可信 unittest 文件 runner，其他 runner 需受保护适配器解释真实计数，未知返回 2。没有操作系统级恶意代码沙箱保证。

## 关键行为覆盖

- Maven、Node、Python、混合栈及 generic/未知显式选择；只生成、不初始化；幂等草案不重写，人工修改拒绝覆盖；分阶段失败和并发 HEAD/分支/脏树停止并按归属回滚。
- 未填 hook、假实现/坏语法、版本类型与精确版本、缺 unit/check/root、产物和 mutable/test/generated/case 范围重叠均拒绝；新 BASE 不能绕过完整性门。
- 初始化五个控制面写入阶段故障注入，恢复 exclude/config/baseline/系统冒烟和能力缓存；预存内容、并发修改与独占锁验证，未放宽旧 init 行为。
- A/B 精确选择（B 故意失败但未被选中）；零执行、全跳过、坏外部计数、重复/越界/链接/硬链接、候选同名包/PYTHONPATH/导入、坏版本和 Unicode/空格路径。
- 同仓并发/跨仓 scratch、同大小/mtime 的实际内容更新、源文件删除、缓存缺失/归属清理、HTTP 错误状态拒绝、本机服务提前退出与进程树回收、清理错误优先于行为红。

健康探针测试只使用本机回环服务，沙箱禁止 socket 时通过自动审核放行该专项；不访问外网或生产。没有使用用户缓存凭证、运行配置、真实数据库或真实模型。

## 独立审查促成的修复

| 发现 | 实际修复与复验 |
|---|---|
| 业务子进程写 argv 暴露的计数文件后 os._exit(0) 能骗绿 | 删除业务可写结果 JSON；可信进程只加载已钉住字节的受保护 case，持有 TestResult；业务仅独立子进程，原攻击返回 2，真实断言仍能返回 1 |
| onboarding 校验后并发 commit 能锁定未校验的新 HEAD | 配置校验前捕获 HEAD/branch，锁内及完成时复查，验证输入摘要；原反例拒绝，无 baseline 残留 |
| 登记服务退出 2 后仍可通过 | ready 后、case 后及 cleanup 前检查非预期退出，环境错误优先；原反例 2 |
| 公开 API 中相对 sys.path 随 cwd 变候选根 | 进入可信区前冻结为原 cwd 的绝对路径，退出恢复；project/mirror 两反例均 2；常规 launcher 原已绝对化 |
| 文档把坏类型业务协议当断言红 | 协议先校验 JSON/键/类型，非零/空/坏协议抛 HarnessError；仅合法 value 不符用断言；直接执行文档字面代码验证 |
