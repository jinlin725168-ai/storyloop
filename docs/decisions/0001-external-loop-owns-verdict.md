# 0001 引擎在仓库外面持有判定权

日期：2026-09-12

## 问题

让一个代理自己写测试、自己跑、自己宣布完成，证据链是断的。人看到的"已完成"只是模型输出的一句话。

## 决定

判定权只在引擎：回归、冒烟、边界审计由引擎在受控进程里执行，结果按退出码和指纹记录；代理（product/smoke/implement/review）都是无状态进程调用，返回的文字（summary、verdict）不构成通过证据。审查角色的 pass 是必要条件，不是充分条件。

## 理由

- 证据必须能被第三方复核：命令、退出码、证据文件的 SHA-256、实现提交。
- 角色分离让每个代理的权限最小：product/smoke 只读，review 只读加受限 Bash，implement 才有写权限。

## 代价

- 每个技术栈要自己写冒烟执行器。
- 引擎要做进程树回收、快照比对，这是代码量最大的部分。
