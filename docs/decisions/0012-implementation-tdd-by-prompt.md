# 0012 实现级先红后绿由提示词要求并记录，引擎不证明

日期：2026-09-23

## 问题

验收级 RED（决定 0002）证明做的是合同里的事，但不保证代码是被单元测试驱动出来的。implement 角色原先的提示词没有要求 TDD。

## 决定

- implement 角色的提示词要求测试先行：每个行为先写单元测试、观察它因预期原因失败、写最小实现、绿灯后重构，结束前跑项目回归命令。
- `design` 增加 `## Tests First` 一节，记录每个测试、实现前观察到的失败、最终的绿灯运行，随 design.md 归档。
- 引擎不验证这一节的真实性，也不在合同提交上重跑单元测试。

## 理由

- 提示词加记录的成本接近零，已经覆盖大部分价值。
- 机器证明需要在旧代码上运行新测试，并区分"导入失败"这类环境错误与真实红灯，复杂度和收益不成比例。用户的决定：第一档就够，别搞复杂。

## 代价

- Tests First 可能被代理敷衍。审查角色能看到它并对照测试文件，这是目前唯一的核对点。
