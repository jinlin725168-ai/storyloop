# 特征化测试

目的：在旧代码上锁定"必须不变"的行为。测试必须在旧代码上通过。

- 期望值来自实测（先跑一遍旧代码看真实结果），不靠读代码推断。
- 按行为面分三类：请求-响应用录制回放；随身份变化的按身份 × 数据范围逐一断言；触发副作用的断言副作用本身（写操作比对落库数据，不只比对响应）。
- 至少一条非管理员身份的用例，避免管理员账号的假绿。
- 会被本次变更扩展的集合用 contains 断言，不用 equals。
- 列出非确定性来源：时钟、没有排序的结果集、易变字段、LLM 调用；LLM 打桩按用例键匹配，不按提示词字节匹配。
- 断言密度按风险：T1 一条非特权主路径；T2 加泄漏点样本；T3 主路径、边界、异常、身份枚举全套。
