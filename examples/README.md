# Examples

Run `python -m storyloop demo runs/demo` from the repository root.

The demo is generated from `storyloop/demo.py` and uses `storyloop/demo_agent.py` as an explicitly scripted adapter. It runs real subprocess acceptance checks and independent boundary probes without a model account or network. Generated run directories are not part of the source distribution.

`todo-demo/` 是入门教程（docs/tutorial.md）用的最小 Python 仓库：复制到临时目录、git init 后即可按教程跑通一次闭环。
