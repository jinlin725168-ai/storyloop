# 通用工具

| 文件 | 用途 |
|---|---|
| `scratch_build.py` | 把 Git 可见文件同步到临时目录后执行构建或测试命令，供实现/审查代理使用，避免工作区出现被忽略文件 |
| `smoke_harness.py` | 冒烟执行器的通用积木：候选副本同步到 scratch、按路径加载 unittest 用例、HTTP 就绪轮询、进程组清理、退出码映射。复制到目标仓库的 `acceptance/tools/` 旁边，再写该技术栈的启动逻辑 |

冒烟执行器的通用形态：候选副本（只有 PATH 和 TMP 环境变量，不能写入）→ 同步到 scratch → 构建与启动 → 跑用例 → 退出码 0 通过、1 行为失败、2 环境错误。`smoke_harness.py` 的模块文档里有最小示例。
